# AstroDeck - A modern, open-source component library and starter kit for building stunning Astro.js websites in minutes. Built AI-friendly for seamless development with Claude, Cursor, and other coding assistants.

#### Preview

 - [Demo](https://themewagon.github.io/astrodeck/)

#### Download
 - [Download from ThemeWagon](https://themewagon.com/themes/astrodeck/)

## Getting Started

1. Clone Repository
```
git clone https://github.com/themewagon/astrodeck.git
```
2. Install Dependencies
```
npm i
```
3. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
